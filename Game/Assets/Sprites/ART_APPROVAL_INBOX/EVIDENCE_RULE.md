# Evidence rule for art approval

An approval decision must refer to a concrete visual artefact that can be inspected.

For every actionable candidate, record:

- exact file or verifiable preview;
- source URL and creator;
- licence;
- asset/version identifier;
- retrieval date;
- intended product role;
- pixel dimensions and scale;
- compatibility findings;
- human decision.

A package name, registry row, licence, or technical test result is not itself a visual candidate.

`APPROVE` is only a human product decision. Runtime promotion is a separate engineering change and must preserve the exact-file provenance.
