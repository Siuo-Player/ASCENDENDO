# ASCENDENDO — Status: Human Playtesting

**Date:** 2026-08-30

Deterministic capture now covers 3 levels × 3 viewport classes = 9 real PPM captures. This proves framebuffer creation and readback for 16:9, 4:3 and 21:9; it does not prove human readability, camera feel, route comprehension, goal salience, or difficulty balance.

The next empirical step is a controlled human-playtesting pilot using fixed current campaign content, the validated viewport classes where available, short repeatable tasks, and both measurable observations and qualitative reports.

The available `PROJECT-STUDIES/ASCENDENDO` material does not currently contain a dedicated human-playtesting protocol. This status therefore records an operational proposal based on the current ASCENDENDO evidence boundary, not a claim extracted from an existing Study.
