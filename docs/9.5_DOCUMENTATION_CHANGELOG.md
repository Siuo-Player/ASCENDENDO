# Tranche documental 9.5 — resumo

Esta branch/PR é **documentação apenas**. Não altera o runtime.

## Alterações

- adicionadas referências a Tiled, Godot e SuperTux e os princípios extraídos dessas ferramentas;
- atualizadas as decisões de produto para incluir fullscreen, layouts adaptáveis, campanha explícita e acessibilidade de teclas;
- especificado o UX esperado do Level Editor e do Campaign Editor;
- atualizado o modelo de interação do Campaign Editor;
- atualizado o plano de migração do renderer para o estado pós-9.4;
- reorganizado o roadmap para separar a tranche UX/campanhas do gate arquitetural seguinte.

## Fontes abertas usadas como referência

- Tiled — editor de mapas open source: https://github.com/mapeditor/tiled
- Godot — editor 2D open source: https://github.com/godotengine/godot
- Godot 2D editor documentation: https://github.com/godotengine/godot-docs/blob/master/tutorials/2d/introduction_to_2d.rst
- SuperTux — jogo/plataformer open source com editor integrado: https://github.com/SuperTux/supertux
- SuperTux Level Editor: https://github.com/SuperTux/supertux/wiki/Level-Editor
