# Tranche documental 9.5 — resumo

Esta branch/PR é **documentação apenas**. Não altera o runtime.

## Alterações

- adicionadas referências a Tiled, Godot, SuperTux e Jump King;
- Jump King está classificado principalmente como referência visual, de composição de telas, linguagem de verticalidade e workflow de edição/playtest, não como especificação da física do ASCENDENDO;
- atualizadas as decisões de produto para incluir fullscreen, layouts adaptáveis, campanha explícita e acessibilidade de teclas;
- formalizado o editor como infraestrutura de longo prazo para criação de mapas pela comunidade;
- formalizado playtest antes de guardar;
- especificado diagnóstico visual do validador, incluindo percurso tentado e causa aproximada da falha;
- formalizada a barra/indicador de força do salto como feedback visual obrigatório, deixando a animação exata para a implementação/UX;
- especificada uma base de conteúdo futura extensível e versionável, sem exigir a implementação imediata de todos os objetos;
- adicionados créditos de assistência por IA para Claude (Anthropic), Gemini (Google) e ChatGPT — GPT-5.6 Luna (OpenAI);
- atualizado o modelo de interação do Campaign Editor;
- atualizado o plano de migração do renderer para o estado pós-9.4;
- reorganizado o roadmap para separar a tranche UX/campanhas do gate arquitetural seguinte.
