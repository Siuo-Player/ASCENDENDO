# 9.6 — Contrato do Level Editor: viewport único

## Objetivo

O Level Editor representa exatamente uma tela lógica de `640x360`. Não é um canvas navegável: o editor de campanha será a camada responsável por navegação entre níveis/telas.

## Contrato

```text
mouse/window
    ↓
windowToLogical
    ↓
logical 640x360
    ↓
editor world (mesmo espaço nesta fase)
    ↓
EditorRenderSnapshot
    ↓
EditorRenderer
```

Não existe transformação de câmera entre estas etapas.

## Invariantes

- cursor e geometria renderizada usam a mesma transformação;
- uma câmera externa não altera a posição lógica do cursor;
- plataformas, preview e seleção não podem ultrapassar `0..640 x 0..360`;
- a moldura do canvas torna os limites visualmente inequívocos;
- pan de câmera não é uma operação do Level Editor;
- qualquer futura navegação espacial pertence ao Campaign Editor.

## Testes mínimos

- cursor no centro → `(320,180)`;
- cursor nos cantos → limites lógicos correspondentes;
- câmera externa não altera o resultado;
- preview fora do canvas fica invisível/rejeitado;
- criação/movimento não permite geometria fora do canvas.
