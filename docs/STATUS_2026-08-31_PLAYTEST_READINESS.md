# ASCENDENDO — Human Playtest Readiness

**Date:** 2026-08-31

## Ready state

Deterministic rendering and capture infrastructure is ready for the first controlled human-playtesting pilot:

- 3 validated viewport classes: 16:9, 4:3, 21:9;
- 3 campaign levels exercised by deterministic capture;
- real PPM framebuffer readback;
- deterministic level selection;
- explicit playtesting protocol;
- structured session sheet.

## Not yet established

No human evidence has been collected by this document. Therefore the following remain OPEN:

- camera feel;
- visual legibility;
- route comprehension;
- goal salience;
- difficulty balance;
- viewport-specific usability.

## Experimental control

During the pilot, freeze gameplay/content and record the exact build commit and viewport. Do not tune camera, geometry, difficulty, or generation between observations within the same pilot unless the experiment explicitly requires a controlled condition change.

## Promotion boundary

A candidate production change requires a repeatable observation, a plausible affected property, a clear player impact, and an isolated retest plan.
